# Douglas Electric Tool Guides

A polished, mobile-friendly website for Douglas Electric that centralizes:

- equipment library
- training videos and resource packs
- manuals and troubleshooting guides
- parts lists and reference materials
- safety center
- search functionality and QR-code access

## Features

- Responsive homepage with a modern layout
- Searchable equipment catalog
- Training, manuals, and safety pages
- GitHub Pages-ready static site structure
- Simple setup for local preview

## Local setup

1. Open the repository folder in your browser or a local static server.
2. Start a simple server from the project root:
   - Python: `python3 -m http.server 8000`
3. Open: `http://localhost:8000`

## GitHub Pages deployment

1. In GitHub, open the repository settings.
2. Go to Pages.
3. Select the branch to publish, usually `main`.
4. Choose the root folder or `/` as the publishing source.
5. Save and wait for GitHub to build the site.

Your site will be available at:

`https://<your-username>.github.io/Douglas-Electric-Tool-Guides-/`
